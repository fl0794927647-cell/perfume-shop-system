# 🏪 نظام إدارة محل العطور

برنامج متكامل لإدارة متجر العطور - متخصص في بيع العطور بالجملة والتجزئة

## ✨ الميزات الرئيسية

### 📦 إدارة المنتجات
- إضافة منتجات جديدة بأسعار مختلفة (100g, 500g, 1kg, 5kg)
- تحديث المخزون تلقائياً
- عرض قائمة كاملة بجميع المنتجات

### 👥 إدارة العملاء
- إضافة عملاء جدد
- حفظ بيانات الاتصال والعناوين
- تتبع العملاء

### 🚚 إدارة الموردين
- إدارة قائمة الموردين
- حفظ معلومات التواصل
- تسهيل عملية الشراء

### 🛒 فواتير البيع
- إنشاء فواتير بيع احترافية
- تتبع المبيعات اليومية
- حساب الإجمالي تلقائياً

### 📥 فواتير الشراء
- تسجيل المشتريات من الموردين
- تتبع تكاليف الشراء
- إدارة المدفوعات

### 📊 التقارير والإحصائيات
- تقارير شاملة عن المبيعات والمشتريات
- حساب صافي الربح
- تحليل الأداء

## 🛠️ التثبيت والتشغيل

### المتطلبات
- Python 3.8+
- pip

### خطوات التثبيت

1. استنسخ المستودع:
```bash
git clone https://github.com/YOUR_USERNAME/perfume-shop-system.git
cd perfume-shop-system
```

2. ثبت المكتبات المطلوبة:
```bash
pip install -r requirements.txt
```

3. شغّل التطبيق:
```bash
streamlit run app.py
```

4. افتح المتصفح على:
```
http://localhost:8501
```

## 📱 الاستخدام

### الصفحة الرئيسية
عرض سريع للإحصائيات الرئيسية:
- عدد المنتجات
- عدد العملاء
- عدد الموردين
- إجمالي المبيعات

### إدارة المنتجات
1. اذهب إلى "المنتجات"
2. اختر "إضافة منتج جديد"
3. أدخل البيانات المطلوبة
4. اضغط "إضافة المنتج"

### تسجيل فاتورة بيع
1. اذهب إلى "فواتير البيع"
2. اختر "إنشاء فاتورة جديدة"
3. أدخل بيانات العميل والمنتج
4. سيتم حساب الإجمالي تلقائياً
5. اضغط "تسجيل الفاتورة"

## 📊 قاعدة البيانات

البرنامج يستخدم SQLite لتخزين البيانات محلياً:
- `products` - جدول المنتجات
- `customers` - جدول العملاء
- `suppliers` - جدول الموردين
- `sales` - جدول المبيعات
- `purchases` - جدول المشتريات
